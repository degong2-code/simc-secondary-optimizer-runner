**상태:** 최신 사용자 직접 결정. `docs/CURRENT_PRODUCT_DEVELOPMENT_STATE.md`와 함께 참조. 2026-10-29 v167~v169의 광범위한 아이템 ID 자유입력·일반장비 후보 조회 노출 설계에 우선한다. 동일 취지와 충돌하는 구형 문서는 역사적 구현 기록이다. 이 문서가 Project Sources/Instructions UI에 실제 등록됐다는 뜻은 아니다.

## 제품 목표
- 탱커·힐러 및 증강 기원사를 제외한 **DPS 26개 전문화**.
- 기본 목표 ilvl **334**, 지원 범위 **266~344** 또는 수동 최종 **CHMV T**.
- 현재 착용 장비를 재분배하거나 장비 세팅/획득 경로를 최적화하지 않는다.
- 사용자가 선택한 **특수효과 조건을 반영한 고정 대표장비**를 기준으로 치명·가속·특화·유연의 **미래 절대 rating**을 SimC DPS 최대화 방향으로 검색한다.
- **SimC가** 아이템 ID·주능력치·무기성능·장비/장신구/장식/소모품의 효과·기본 APL·실제 DPS를 계산한다. 우리 코드는 대표 프로필/슬롯/ilvl/옵션 및 정확 rating 예산·캐시·95% 통계를 책임진다.

## 사용자 입력에 노출할 장비
1. **장신구:** 이번 시즌 제품 DB의 장신구 목록에서 정확히 **2개 선택**. 일반 UI에서 임의 ID 텍스트 입력 없음.
2. **비장신구 특수효과 장비:** 이번 시즌 DB에 특수효과 후보로 분류된 아이템만 **선택 사항**으로 제공한다. 일반 UI에서 임의 ID 텍스트 입력 없음. 실제 SimC 효과 지원 자체에 대한 독립 인증 Gate는 만들지 않는다. 정확한 Native 정적 스탯 `L`이 필요한 조건은 기존 안전한 캐시·차단을 유지.
3. **장식 제작장비:** **최대 2개**의 장식·선택 제작 스탯을 받는다. 정확한 제작 장비 ID·SimC 옵션의 **예외적인 수동 입력 허용**. 일반 아이템 전체 ID 검색 기능으로 확장하지 않음. 제작 50:50 초기 스탯은 L로 잠그지 않는다.
4. 직업·전문화·종족·특성, 목표 ilvl/수동 T, 보석·영약·음식·물약·기름·전투조건은 기존 제품 입력을 유지. 사용자의 전체 착용 장비 목록을 요구하지 않는다.

## 이번 시즌 신화+ 복귀 던전 장비 — 최신 추가 승인 (2026-10-29)

- 사용자 직접 결정: **이번 시즌 신화+ 던전과 연결된 장비는 과거 확장팩 `ExpansionID`, Journal `DisplaySeasonID=0`, 미해석 `WorldStateExpression` 때문에 시즌 선택 DB에서 누락하지 않는다.** WCL에서 이번 시즌으로 확인되고 같은 빌드 DB2에 연결된 **8개 신화+ 던전 전체**의 Journal 장비를 시즌 후보에 포함한다.
- v166에 조건부였던 **223개 = 장신구27 + 비장신구 특수효과 후보4 + 일반장비192**를 v171에서 포함했다. 보수적 배제 후 장신구36→**63**, 특수효과10→**14**, 내부 일반장비136→**328**. 기존 제작106 유지. 시즌 장비 후보 총 288→**511**, 별도 세트 미분류2는 사용자 선택 대상이 아니다.
- 시즌 던전의 아이템 후보라는 **수집·선택 적격성**과 개별 아이템의 실제 드롭 시점/조건/SimC 변형·효과 지원에 대한 **확정**은 구별한다. WorldState 불명은 **후보 미노출 근거가 아니라 미확정 표시 근거**다. 허위 시즌 드롭 확정 문구·자체 효과 인증 Gate를 만들지 않는다.
- 새 아이템을 사용자 임의 ID 입력으로 해결하지 않는다. 최신 시즌 DB를 한 번 갱신하고, 웹 화면에서 장신구/선택 특수효과 목록으로 제공한다. 일반장비 192개는 **사용자 조회/선택 금지**, 내부 대표장비 선정에만 사용할 수 있다. 기존 프로필·최적화/캐시 identity 자동 변경 없음.
- 세 장신구 `250215` Freightrunner's Flask, `273796` Vile Vial of Volatile Venom, `273649` Stormbound Emblem of Dazar가 이번 갱신으로 실제 제품 선택 목록에 포함되었다. 세 아이템의 Native 실제 수용과 정확 효과는 여전히 SimC 책임이다.

## 내부 장비 엔진 (사용자 선택 금지)
- **일반 대표 방어구·장신구 외 일반 장비·무기·티어 4세트**는 프로그램 내부에서 자동 결정. 그 장비들의 여러 대안을 사용자에게 보여 선택하도록 만들지 않는다.
- 현재 시즌 소형 DB의 일반 아이템/무기 분류와 전문화별 방어구·무기 호환 후보 조사는 **초기 대표장비 선정·내부 테스트**에만 활용. 대표 프로필 확정 뒤 사용자용 일반 장비 후보 조회 기능은 없앤다.
- `v139/v167/v168/v169`의 내부 후보/티어/무기 컴파일러는 개발용 기능으로 남아도 **사용자 웹 API에 일반장비 후보나 물리 프로필 목록을 노출하지 않는다**.
- 대표장비가 실제 SimC 수용 전이면 새 프로필을 기본 실행 경로로 자동 승격하지 않는다. DB2 direct effect-record 부재만으로 모든 SimC cantrip/특수효과 부재를 확정하지 않는다.
- 누락된 시즌 특수효과 장비는 일반 사용자의 임의 ID 입력으로 해결하지 않고 시즌 카탈로그를 정정·갱신한다. 기존 세션의 과거 정확 ID는 보존하여 조회·동일 세션 재개 가능하나 **새 계획**은 현재 시즌 선택을 요구한다.
- 일반 장비 스탯 분배를 사용자가 장비별로 조정하지 않는다. 대표 아이템의 2차 스탯을 최적화 제약으로 삼지 않으며, 내부 `gear_*` 후보에 자유분배 스탯을 반영한다. 특수 장비 정확 L만 하한으로 보호.
- `T=G+J+F+O`, 자유 `B=G+J+F`, `T=B+O`. O는 `gear_*`에 고정 1회, L은 G/B 내 포함·별도 더하지 않음. 장신구 정적 스탯은 자유 G 밖. Native JSON2 누락을 0으로 추정하지 않는다.
