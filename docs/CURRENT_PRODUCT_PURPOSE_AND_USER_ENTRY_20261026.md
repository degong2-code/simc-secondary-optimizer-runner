## Product target, not equipped-gear rebalance
Users optimize **future target-itemlevel CHMV absolute rating goals** (default ilvl 334), not the distribution of their currently worn full gear. Users specify class/spec/race/talents, desired target ilvl or manually chosen final CHMV T, two trinkets, only special-effect items they want fixed, 0–2 embellishments, appropriate gems/consumables/oil and combat conditions. Users do **not** choose every item or supply the current gear total. The product outputs observed best absolute Crit/Haste/Mastery/Vers ratings, DPS and SEM, 95%-only certainty information, percentages, and observed materially distinct near-DPS alternatives. It does not recommend loot sources, farming routes or gear combinations, nor create a comprehensive item DB.

## User input versus internal SimC execution
The program internally builds a **target-ilvl representative setup**: appropriate primary-stat scaling and weapon performance, standard generic gear, four tier pieces, user-fixed special items, trinkets and embellishments, source-backed default SimC APL and combat. An optional imported SimC profile primarily supplies **class/spec/race/talents**; its current equipment and current total do not become the target. A full SimC profile text, filler file and initial candidate vectors are currently required by `runner/v096_unified_product_entry.py`, but those are **internal source-prepared input obligations, NOT mandatory final user UI fields**. This is the highest-priority practical integration gap.

## Budget policy and modes
Approved official final total **T=G+J+F+O**, internal free budget **B=G+J+F**, hence **T=B+O**, candidate `c_final=c_base+o`. O is fixed, added exactly once within `gear_*`; special nontrinket static L is already included in G/B and protected as floors (no double-add). Trinket static stats are outside G and missing static JSON2 rows never imply zero or prevent selection. Initial crafted 50:50 distributions are not fixed floors.

The practical ilvl default may use the existing **v087 79-level × 2-track Native-derived rounded B registry**: normal/common (334: B3150) or Fury Titan's Grip dual two-hand (334: B3350). Its 10-rating rounding has ±5 difference from measured representative input, **not exact G across every user gear variant or specialization**. Manual user final-inclusive T takes precedence (v097 linked and tested). Preserve **exact Native G as an optional precise representative-budget path**, not a mandatory default flow and not an acquisition of the user's equipped gear data. Exact selected fixed special L is still required, as is correct representative item/ilvl/options and SimC input integrity.
