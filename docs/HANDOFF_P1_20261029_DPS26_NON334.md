## 1. 본 제품 목표와 수학/권한 불변식
목표 ilvl(기본 334) 또는 **사용자 수동 최종 CHMV 총량 T**에 도달했을 때 미래 파밍 목표가 될 치명·가속·특화·유연의 **최적 절대 rating**을 SimC DPS로 탐색한다. 현재 착용 장비 스탯 재분배기가 아니다. 전역 최적해를 입증하지 않은 경우 그 한계를 표기.
- 사용자: 직업/전문화(승인 26 DPS), 종족/특성, 목표 ilvl 또는 수동 T, 장신구 정확 ID 2개, 선택 특수장비(웹 최대 8), 장식 최대 2, 보석/영약/소모품/기름/전투조건. 전체 장비 목록/완전 SimC 프로필/내부 filler·seed·SHA 입력 **필수 아님**. SimC 프로필 업로드는 캐릭터 정보/특성만 가져오는 선택 편의 기능.
- 내부: 시즌 대표 일반 장비·4티어·무기·주능력치·SimC 기본 APL 구성. **SimC는 아이템/효과/발동/APL/전투 DPS 책임**. 자체 효과 계산·발동 인증 Gate·직업별 APL 신설 금지. 별도 시즌 전수 장비 DB 금지. 대표 아이템 선택표 + SimC 로컬 DB 우선.
- **T = B + O, B = G + J + F; 최종 c = c_base + o.** 기름 고정 O는 `gear_*`에 한 번만; 고정 특수장비 스탯 하한 L은 G/B 안에 이미 포함, 중복 가산/자유화 금지. 장신구 고정 스탯은 자유 G 밖이며 gear 레코드 미출력 ≠ 0 확정. 제작 초기 50:50을 L로 잠그지 않음. 수동 최종 T는 기름 포함이고 기존 레거시 B 의미를 명시 변환. 334 일반 B=3150; 기름 무기 1개 O32, 두 무기 O64 (Fury 양손쌍수 B3350). 다른 ilvl은 기존 **79×2 Native 유래 266~344 반올림 B 참조표**로 계획, 실제 물리 Native 수용을 대체하지 않는다.
- 통계: **95%만**, 관측 DPS 1순위와 95% pairwise 방향 지지/미확정, SEM·근접 분배 대안·비율·전역 최적해 미입증을 분리.
- 정적 아이템 캐시는 같은 시즌 SimC revision만으로 전면 폐기 금지, 교정은 명시적 요청+증거. DPS cache는 binary SHA/revision·정확 프로필·장비/options·후보·O·iterations·전투조건 identity로 구분. 완료 원본 JSON2/receipt·seal은 불변.
