[반드시 이해할 목표]
현재 장비 스탯 재분배가 아니라, 목표 ilvl 기본334 또는 사용자가 지정한 최종 CHMV 총량에 대한 미래 파밍 목표 **치명·가속·특화·유연의 최적 절대 rating**을 실제 SimC DPS로 찾는다. 일반 사용자는 전체 착용 장비를 입력하지 않는다. 공통 대표 일반장비·무기·티어4·원본 APL은 내부 생성; 사용자 입력은 직업/전문화/종족/특성·목표·장신구2·특수장비·장식 최대2·소모품/보석/기름·전투조건. 결과는 관측 DPS, SEM, 95% 통계적 판정, 관측 1순위, 실질적으로 다른 근접 대안, 절대 rating과 비율이다. 전역 최적 입증과 관측 최고는 구분. 총량 T=G+J+F+O, 내부 B=G+J+F, T=B+O, 고정 O는 gear_* 한 번, 선택 장비 L은 B 안에서 floor 보호, 장신구 정적 스탯은 G 외부. v087 기본 B3150(334 일반)·B3350(분노 양손2개)는 10-rating 반올림 참조이지 모든 전문화의 exact G가 아니다. SimC가 아이템 효과/APL/proc/DPS를 책임진다. 별도 최적화 엔진/효과 인증 Gate/시즌 장비 DB/파밍 경로 추천 금지.
