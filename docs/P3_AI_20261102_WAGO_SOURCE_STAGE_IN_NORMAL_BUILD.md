## Actual implementation
- `POST /api/v1/environment/build` accepts an explicit `fresh_season_build` (four-part game build) in the existing UserRequest. It takes precedence over the installed current-season guard and enters `LocalJobs.collect_fresh_source`, not the previous `jobs.plan` path. Old installed-season requests are unchanged. `/api/v1/sessions/plan` and `/api/v1/sessions/start` explicitly BLOCK `fresh_season_build` with `FRESH_SOURCE_NOT_INSTALLED`, avoiding an accidental historic-profile run. Product UI does **not yet** discover the latest build or expose an autonomous new-season Build flow.
- The same original `v216_environment_build_coordinator` owns `collect_wago_new_season_source`: invokes existing `v161_wago_db2_snapshot.snapshot` with a caller-provided pinned build, exact 10 tables on wago.tools, `make_archive=False` for runtime (legacy v161 ZIP mode remains default for historical workflow). Runs one `v217.execute_stage` against a dedicated `_fresh_season_sources/wago_<build>` workspace within the app's session root. Same-process API requests are lock-serialized. An unchanged validated stage skips all external downloads; changed output bytes fail closed without overwriting previous evidence. v217 retains its interrupted RUNNING recovery contract.
- v161 receipt now includes URL per DB2 table, target build and UTC collection time, file sizes and SHA; v217 stage seals all raw outputs. Source receipt SHA is cross-checked against the stage's actual streamed file hash **without a second full DB2 read**. v217 output hashing now streams in 1MiB chunks rather than loading a possible 210MB CSV into memory. Stage code identity hashes only the collector + v217 to avoid unrelated v216/UI changes invalidating unchanged same-build source evidence.
- Public stage status is `FRESH_WAGO_DB2_COLLECTED_MORE_SOURCES_PENDING`, `environment_ready=false`, `environment_installed=false`, `source_season_verified=false`, G/J/F/O/B/T all null, native 0. This stage **does not call** v163 season join, v168 tier, v165-v167 gear, v189/v190, v191-v213, v222 or v212 automatically yet. It returns a source receipt path for internal follow-up; normal UI source discovery/installation remains unfinished. Current installed season does not provide budget/ID seed in new source mode.
