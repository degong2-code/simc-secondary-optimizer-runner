# P3-BP (1차) — 원본 증거 1회 판정·후속 재사용: v217 Wago SHA 재검증 중복 제거

2026-11-03 · 격리 브랜치 `probe/chat-cache-v035-20261024`

## 최신 사용자 직접 결정

원본 수집 단계에서 **해당 시즌에 파밍 가능한지, 아이템 ID·효과/품질/사용 조건을 신뢰할 수 있게 검증한 사실**은 후속 단계에서 다시 동일한 외부 조사·Native 시험·인증 Gate로 확인할 필요가 없다. 후속 단계는 봉인된 출처/조건과 요청의 동일성만 재사용하고, 해당 원본에서 아직 **증명하지 못한 사실**만 최소 비용으로 보완한다. 한 번 확인됐다고 모든 효과/모든 변형/다른 시즌까지 승인하지 않는다. 신규 시즌도 같은 엔진·같은 계약을 사용한다.

## 실제 코드 변경

- `v216` 정상 수집: 기존 `v217.execute_stage`가 Wago TABLES 전체 바이트를 SHA 계산하고 정상 재사용 시에도 검증한다. 봉인된 실제 파일 SHA/크기를 `stage_doc.outputs`에서 추출하고 원래 `v161` 다운로드 영수증과 한 번 대조한 뒤, `v163.build_index`와 `v190.build`에 전달한다.
- `v163.verify_snapshot`: 이미 검증된 `verified_tables`가 전달되면 자체적으로 전체 10개 DB2 CSV를 **또** 해시하지 않는다. 원래 영수증의 테이블명·크기·SHA 동일성은 비교한다. 독립 실행 또는 증거 미전달이면 기존 모든 테이블 SHA 실측을 그대로 수행한다.
- `v190.build`: 정상 Build의 동일 `Item`/`ItemSparse` 원본 SHA를 재사용해 두 테이블 재해시를 생략한다. CSV 항목의 분류·확장팩 필터·미승인 판정은 기존대로 처리한다. 독립 실행 시 원본 전체 해시 경로 유지.
- `v221.join`: `v216._fresh_gem_item_source_stage`가 이미 `_verify_db2`로 직접 확인한 `Item`/`ItemSparse`의 SHA를 동일 호출 안에서 재사용한다. 원본이 변한 상태의 독립 실행은 기존과 같이 차단한다.
- 신규·추가 테스트: `test_v190_consumable_item_snapshot_join`, `test_v221_gem_item_db2_relation`, `test_v259_v217_source_seal_reuse`. 강제 재해시 탐지, 영수증 불일치, 선행 v217 단독 검증 및 동일 파일크기 변조 거부를 검증하도록 작성했다.

## 검증과 증거의 정확한 범위

- 코드는 GitHub 격리 브랜치에 실제 커밋됨. **변경 후 CI 실행 결과는 아직 읽지 못했으며 신규 PASS를 주장하지 않는다.** 이전 P3-BO 430 PASS는 회귀 참고일 뿐 본 변경의 실행 증거가 아니다.
- 본 변경은 파일 무결성 증거의 중복 해시를 줄인다. 새로운 아이템의 **시즌 파밍 가능성, 티어·장비 ID, 최고 품질, G/J/F/O 숫자, 유효 무기 손, 영약·보석 적용, Policy A/READY**를 새로 확정하지 않는다.
- 기존 `v163`가 제공하는 WCL/DB2 시즌 관계는 일부 선택 부위의 근거지만, 아직 `v232`의 전체 대표 장비·티어에 대해 시즌 이용 가능성이 확정된 것은 아니다. 실제로 원본 단계에서 증명된 부위는 이후 동일 검증을 반복하지 않는다. 반대로 WSE 조건·Localbots-only·시즌 출처 미확정 부위는 아무 근거 없이 승격하지 않는다.
- SimC는 아이템 효과/proc/APL/DPS 주체다. 별도 효과 인증 Gate를 만들지 않는다. 원본 해시 무결성 확인과 게임 콘텐츠 적격성 확인은 서로 다른 책임이다.
- 실제 신규 외부 HTTP 호출 0, 실제 신규 Native 호출 0(이번 GitHub 코드 수정 자체). 추가적인 전체 Wago 수집·전체 전문화 Native 전수 시험 없음. 전체 SHA 재사용에 따른 I/O 감소량은 아직 실측되지 않았다.
- v217의 원본 SHA 재검사 자체는 저장된 파일의 변조를 방지하기 위해 유지한다. 이 처리는 해당 아이템의 시즌 적격성을 **재판정**하는 절차가 아니다.
