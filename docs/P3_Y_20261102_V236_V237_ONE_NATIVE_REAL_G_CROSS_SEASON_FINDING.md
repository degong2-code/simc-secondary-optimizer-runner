The older PvP equipment was eligible under v232's heuristic (same item quality, unscaled level search window and physical class/spec masks), but **those conditions are not evidence of same-season membership**.

This is NOT a Native item-resolution failure or a false G arithmetic sum; it is a **season-identification / representative-candidate correctness failure**. The selected stat mixture is unusually versatility-heavy as expected for the observed PvP-style equipment, but the audit does not infer a game-season origin from item ID alone: it uses the **Native-resolved item names and source identities to document actual mixed candidates**. The engine still must verify actual authoritative season/gear eligibility, not infer it from ID magnitude or item name heuristics.

**Verdict**: `PASS_NATIVE_STATIC_OBSERVATION`, `FAIL_ACTIVE_SEASON_REPRESENTATIVE_AUTHENTICATION`, `G/B/T_NOT_APPROVED`.
