# v441 — 78개 수락 조건의 제품 필수성 전수 검토·검증 절차 간소화 (78/78)

> 기준: 최신 사용자 직접 지시(78개는 제품을 완성하고 결함을 조기 발견하기 위한 관리 요소), 과거 승인된 [v401 정책](POLICY_78_ELEMENT_COMPLETION_GATE_V401.md), [운영 헌장](OPERATING_CHARTER_FUTURE_SEASONS_AND_EVIDENCE_20261113.md), v409 A8 검증 간소화, v405 A7 WSE 비차단. **이 감사는 상태 PASS 승격, 원본 측정, 새 Gate가 아니다.**

## 판정 원칙

- 제품 오류를 막는 **핵심 경계**(선택 item ID/ilvl/슬롯·4pc, 현재 사용 시즌 G/J/F/O, L/E/O 중복과 정적 rating, SimC 입력/DPS, 95%와 캐시 정체성·취소/재개)는 유지한다.
- 실제 사용자 선택과 무관한 아이템·확장팩 모듈·전문화별 독립 Native/실측·SimC 내부 proc/APL 인증·전역 최적해 증명·과거 시즌 수치 전용은 수락 조건이 아니다.
- 데이터 의존 원본은 필요 범위에서 실제 시즌 검증을 유지한다. **시즌 독립 RUN**은 정상/오류 회귀와 기존 실 Native 사례의 경계 증거를 공유하며 매 시즌 같은 산술/통계 알고리즘을 다시 입증하지 않는다.
- **요소별 PASS는 독립적으로 유지**하지만 하나의 봉인된 영수증·Actions가 여러 ID의 실제 수락 조건을 직접 지원할 경우 함께 귀속할 수 있다. 미관측을 PASS로 자동 승격하거나 빈 인증으로 갈음하지 않는다.
- 최소 1건의 실제 제품 E2E가 다른 요소들의 사용·실패 경계까지 확인했다면 공유하되, 선택하지 않은 옵션을 실증했다고 주장하지 않는다. 기본 환경 READY와 옵션별 READY를 분리한다.
