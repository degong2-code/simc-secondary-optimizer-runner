## 판정 용어

`CODE_IMPLEMENTED` ≠ `OFFLINE_PASS` ≠ `REAL_NATIVE_PASS` ≠ `USER_WEB_E2E_PASS`. **미검증**과 **재현된 실제 결함**도 별도. 실 실행의 SHA/SimC binary/프로필/옵션/CHMV/O/iterations/전투조건 일치를 검토해 캐시를 재사용하고, 95%는 선택편향·전역 미증명을 명확히 한다.
