> **목적:** P3 번호를 순서대로 읽지 않고도 **무엇을 재사용할지 / 무엇이 실제 검증됐는지 / 어디만 아직 부족한지** 빠르게 결정한다. 상세 P3 이력은 링크로 찾아가며, 최초 검토 때 역사 원본 전체를 재감사하지 않는다.

## 검색 방법 (필수, 4단계)

1. **아래 A~G 중 요청 기능의 상위 영역 1개를 먼저 고른다.** 교차 분야가 있으면 필요한 연결부 1~2개만 추가한다. 각 행의 `구현·재사용 진입점`으로 코드와 source/receipt identity를 찾는다.
2. **Evidence ≠ Integration.** 실제 소스/Native/CI 증거가 입증하는 시즌·빌드·binary·프로필·옵션·SHA 범위를 확인한다. 소스 관측/오프라인 PASS/준비된 옵션을 **실제 제품 READY/발행**으로 읽지 않는다.
3. 다음 행동을 `REUSE` / `CONNECT` / `EXTEND` / `NEW` / `STOP` 중 결정한다. **같은 내용의 수집기·파서·Native·Gate 추가 전에** 이 라이브러리의 기존 함수·캐시를 먼저 사용한다.
4. 작업 후 **해당 기능 행과 아래 16키 호환 표의 최근 노트 링크만** 갱신한다. 실패 기록과 상세 P3 노트는 남겨 두되, 이 라이브러리에 시간순 연구 내역을 누적하지 않는다. 새 채팅은 이 문서의 *관련 영역*부터 읽는다.

**현재 제품 Gate:** 미래 목표 ilvl 기본 334 또는 수동 최종 T → 대표 일반 장비·무기·티어4의 검증된 G, 최고품질 기본 보석 J, 영약 F, 선택 기름 O → `v222`의 `B=G+J+F; T=B+O` (수동 T 우선, L/E/O 중복 없음) → 정책 A 실제 사용자 선택지 발행 → `v212` 신규 시즌 설치 **READY/T1**. 현재 **미완료**. 이후 `v098→v096/v094` 기존 적응형 SimC DPS(SEM·95%·대안·캐시·재개) 통합. 26 DPS만 지원, 증강·탱커·힐러/현재 장비 재분배·시즌 장비 추천 DB/독립 효과 엔진 제외.
