# IDEA-004 — 비용 인지형 지식 기울기 탐색 (Cost-aware Knowledge Gradient)

- **제안:** 2026-11-11, 현재 진행 상태 점검 채팅. **상태:** `IDEA_ONLY`, 알고리즘 미구현·신규 Native 실험 0회.
- **가설:** SimC는 조합마다 실행시간과 노이즈(SEM)가 다르고, 모든 미측정 후보가 동등하게 유용하지 않다. 다음 후보를 '예측 DPS가 가장 높은 곳'이 아니라 **그 후보를 실행하면 최종 1순위 판단이 얼마나 개선될지 / 추가 실측 비용**으로 순위화하면 5~10분 안에서 의사결정 품질을 높일 수 있다.
- **탐색 절차:** 동일 신규 SimC 사용자 프로필/예산에서 후보별 실제 DPS·SEM·runtime을 수집 → 기존 결과로 각 후보 DPS의 불확실성 및 다른 후보와의 순위 역전 가능성 추정 → 각 후보의 가상 측정 후 예상 최고 확인 DPS 또는 순위 불확실성 감소량을 수치적으로 근사 → `가치/예상 SimC 초`가 높은 후보·미조사 지역을 배치로 재측정 → 마지막 정밀 확인 SimC는 실제 95% 판정만 사용.
- **비교 대상과 차별점:** v312의 고정 8 UCB+5 지역+3 탐사보다 **후보 정보 가치/비용**이 선택 기준. IDEA-001은 단계별 iterations 승급, IDEA-002는 영역별 반경, IDEA-003은 공간 셀별 조사 비율을 다루므로 독립 가설이다.
- **우회·과장 금지:** 예측 분포와 측정 가치 자체는 대리모델 가정이며 SimC DPS 관측도 95% 통계적 우위도 아니다. 실제 SimC native JSON2·iterations·SEM·전투조건·프로필/바이너리 SHA를 근거로 검증하고, 선택편향/다중 비교를 별도 표시한다.
- **효율 검증:** 동일 8 DPS 전문화×2 신규 프로필/초기 seed에서 v290·v312·IDEA-001~003과 동일 5·10분, 실제 Native/iterations 및 최종 320+ 재확인 DPS·SEM 비교. 모델 피팅 오버헤드와 신뢰구간 오류도 포함한다. 16개 새로운 프로필 v314 실측은 현재 사용자 지정 v313 뒤 실행하도록 유지.
- **위험:** KG 근사계산이 SimC보다 비싸질 수 있음; 샘플링 편향이나 잘못된 SEM 기반 불확실성 추정으로 정보 가치가 왜곡될 수 있음. 처음엔 수백 개 이내 후보 풀과 작은 Monte Carlo 또는 폐형식 근사로 상한을 봉인하고 동일 조건에서 원본 실측으로 검증.
- **상태 승격:** 실제 SimC 없는 IDEA_ONLY. 26전문화 범용성/전역 최적·familywise95 입증 아님. v290 기본 정책/메인 브랜치 불변.
