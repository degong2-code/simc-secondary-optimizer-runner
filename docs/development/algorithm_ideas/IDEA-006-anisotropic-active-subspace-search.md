# IDEA-006 — 국소 민감도 방향에 따른 비등방성 탐색 (Adaptive Active-Subspace Geometry)

- **제안일:** 2026-11-11 (이전 누락 제안 보완 2/3). **상태:** \`IDEA_ONLY · INTEGRATE_ABLATION_FIRST\`. 구현/Native 검증 0회.
- **분류:** 새로운 DPS 함수가 아닌 **허용 CHMV 공간에서 다음 후보의 이동 방향·스텝을 고르는 기하학적 옵션**.
- **관측된 문제와 발상 이유:** v290은 치명·가속·특화·유연의 정수 예산을 지키며 두 스탯 사이를 옮기는 \`_bounded_fraction_neighbors\`를 사용한다. v303은 지역의 반경/배분을, v312는 전체 3차 반응곡면/고정 배치를 사용한다. 이들은 국소적으로 **어느 스탯 조합 방향으로 DPS가 빠르게 바뀌는지, 어느 방향은 거의 평탄한지**를 직접 제약 단체의 지역 스케일에 반영하지 않는다.
- **메커니즘:** \`c+h+m+v=B\`와 스탯별 하한·상한이 맞는 **3차원 자유좌표계**에서, 한 유망 지역의 실제 저/중정밀 SimC 측정 이웃 중 분리된 충분한 수를 골라 정규화·강건 회귀된 국소 2차 모델을 적합한다. 추정 변화율/곡률(3×3 Hessian)의 고유방향을 사용하여 **평탄한 방향은 더 길게, 급격한 방향은 더 짧게** 정수 rating 후보를 제안한다. 4번째 스탯은 반드시 \`B-sum(나머지 3)\`로 결정하고 Native 허용 경계·L/E/O·동일 vector 중복을 검사한다. 경계 근처는 tangent cone과 실제 정수 타당성으로 클리핑, 회귀 불안정 시 원래 v290 pairwise로 되돌린다.
- **효율적으로 작동할 합당한 이유:** 국소 DPS 등고선이 기울어진 골짜기/능선을 가진 경우, 단일 스탯 교환축만 따라 짧게 반복하는 것보다 **실제 상관된 개선방향을 따라 한 번에** 움직여 필요한 SimC 후보 수를 줄일 수 있다. 총 예산을 유지한 상태에서 좁은 방향과 완만한 방향의 스텝을 다르게 쓰는 이유가 있음. 단, 모든 전문화에 부드러운/차별화된 국소 곡률이 있다는 증거는 없다.
- **장점:** Hessian 3×3 계산은 SimC 반복 대비 가벼울 가능성; SimC 자체를 변경하지 않음; v303의 지역 관리/IDEA-002의 반경 확대에 들어갈 **이동방향 제안기**만 바꿔 시험 가능; 공통 B·정수성 유지.
- **단점·실패 조건:** 저 iterations DPS가 시끄러울 때 고유방향 추정이 불안정; 부드럽지 않은 proc/가속 브레이크포인트/스탯 상한/고정 L 근처에서 국소 2차 모델 실패; 회귀에 많은 국소 표본이 필요하면 기존 v290보다 **추가 Native 비용**이 커진다. 수치적으로 작은 고유값의 역수를 무제한 사용하면 대폭 잘못 이동.
- **기존 아이디어/정책 중복:** v290의 pairwise 이동, v303·IDEA-002의 trust radius, v312의 3차 surrogate와 **부분 중복**. 신규 부분은 **지역 내 움직임의 비등방성 방향/스케일**이며, 전역 모델 예측으로 DPS를 대체하지 않는다. IDEA-003은 공간 셀별 예산, IDEA-001은 iterations 재측정으로 역할 구분.
- **통합 판단:** \`INTEGRATE\`: v303 지역별 후보 생성기에 조건부 방향 metric만 붙이고, 실패하면 원래 v290 pairwise로 자동 복귀. 별도 전체 최적화 엔진·새 장비 DB 만들지 않는다. v312 모델과 결합하면 두 번 fit을 할 수 있으므로 **모델/표본 공유의 CPU 절감 효과**를 먼저 평가.
- **반증 시험:** (1) 원본 9,906 실측에서 미래 지역의 실제 고점 값을 모델 학습에 흘리지 않는 차단 holdout으로 지역 방향 예측 품질을 계산; (2) 새로 생성한 8 DPS 전문화×2 분포에서 **동일 5/10분 wall + 총 iterations + 초기 후보**와 v290 pairwise 및 v303 고정 반경을 비교; (3) 최종 320+ 실측 확인 DPS와 발견 속도, 수렴 실패율, 후보 생성 CPU/중복률과 경계 위반 **0** 확인. 지역 Hessian의 부호/방향이 부트스트랩에 따라 불안정하면 ablation 중단.
- **효율이 생길 *필요조건*:** 국소 실제 DPS 지형의 방향성 차이가 35-iteration 노이즈를 넘어서 반복적으로 관측되고, 그 방향을 따라 제안한 유효 새 후보가 원래 pairwise보다 높은 DPS를 **동일 계산량**에서 자주 발견해야 한다.
- **증거/표기:** 아이디어·가설 단계. 모델이 예측한 DPS는 관측 SimC DPS 아님, 전역 최적/95 superiority 주장 금지.
