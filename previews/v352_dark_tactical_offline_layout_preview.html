    종족 미입력 시 dwarf를 사용합니다.

    특성 미입력 시 선택한 전문화의 검증된 기본 대표 특성을 사용합니다.

    이번 시즌 장신구·특수효과 선택 목록 확인 중 · 일반장비·티어·무기는 내부 자동 구성

    최신 시즌 대표 장비·직업별 티어 4세트·무기는 항상 내부 구성합니다. 목표 아이템레벨 266~344에 맞춘 독립 세션입니다.

    실제 SimC 대표 프로필 26/26 수용 검증. 기존 계산은 저장되며 같은 조건에서 재사용됩니다. 다른 특성·장신구·특수효과 조합의 성공 여부는 각 SimC 실행으로 판단합니다.

    소켓 수·특수보석·영약·기름은 개별 최적화 조건입니다. 선택을 바꾸면 해당 시즌의 J/F/O와 실행 프로필을 다시 검증해야 하며, 검증 전에는 자동으로 이전 구성의 예산을 적용하지 않습니다.

    보석 소켓 구성 · 기본 일반보석 4개 (수정 가능)

    이 수치는 특수보석을 포함한 전체 소켓 수입니다. 기본 4개는 치명·가속·특화·유연 일반보석 각 1개이며, 선택 특수보석 1개를 포함하려면 총 5개 이상이어야 합니다. 변경할 때마다 새 J 예산·보석 배치가 검증되어야 하며, 이미 저장된 과거 최적화 세션에는 소급 적용하지 않습니다.

    일반보석 4개 + 특수보석 0개 = 전체 소켓 4개

    고급 입력: 이미 선택한 특수보석 ItemID (일반 사용자 입력 불필요)

    아이템 ID를 직접 알고 있어 특정 소켓 구성을 재현할 때만 입력합니다. 일반 사용자는 입력하지 않아도 되며, 특수보석 효과 계산은 SimC가 담당합니다.

    일반보석은 4종을 기본으로 배치하고 소켓이 더 많으면 4종을 순환합니다. 확정 J는 해당 시즌의 실제 보석·품질·소켓 근거로만 등록합니다. 모든 효과 계산은 SimC가 담당합니다.

    영약 · 사용자 선택

    기존 설치 영약만 표시하며 최고 품질 우위를 추정하지 않습니다.

    미등록 품목 검증 준비 · 정확한 ItemID 입력 (고급)

    영약·무기 기름의 물리 ItemID는 일반 사용자가 시즌 구축을 위해 조사하는 항목이 아닙니다. 환경 엔진이 시즌 원본을 수집·검증하고, 검증된 선택지는 캐릭터 설정에서 이름으로 선택하는 것이 제품의 목표입니다. 아래 입력은 이미 정확한 ID를 알고 있는 제한적 재현·검증 경로이며, 현재 자동 품목 등록이 모두 완성됐음을 의미하지 않습니다.

    신규 영약 ItemID 검증 준비 (고급)

    위 검증된 영약 목록에서 선택하면 정확한 물리 ID가 자동으로 입력됩니다. 새 환경 요청은 원본 v216이 다시 검증하며, 설치 영약이라는 이유만으로 다른 조합의 승인을 부여하지 않습니다. 직접 입력도 유지합니다. 선택한 경우 기존 같은 시즌 v281 원본에서 이 영약만 찾아 F Native 측정(별도 선택)을 진행합니다. 없는 ID나 관측상 더 낮은 품질은 보류하며, 다른 영약 전체를 측정하지 않습니다. 정확한 ID를 모르면 비워 두세요.

    신규 무기 기름 ItemID 검증 준비 (고급)

    일반적인 장비 선택 항목이 아닙니다. 기름을 지정하면 같은 시즌의 실제 아이템·품질·손/무기 적용 조건과 SimC 정적 rating을 기존 환경 엔진에서 확인합니다. 영약 ID도 함께 지정해야 하며, 검증이 끝나지 않은 항목은 등록하지 않습니다. 기름 종류가 같은 손에 여러 개 설치된 경우 일반 사용자 세션에서 임의로 하나를 고르지 않습니다.

    기본 4개 일반보석·기름 미사용 구성은 기본 환경의 검증 결과를 사용합니다. 변경한 구성은 같은 시즌 원본으로 다시 확인해야 합니다.

    최적화 상세 설정

    치명·가속·특화·유연에 공통 적용합니다. 선택한 기름(O)까지 포함한 최종 rating에 적용되며 고정 L/E/F/O는 재분배되지 않습니다.

    새 최적화 세션은 기본적으로 기름을 사용하지 않습니다(O=0). 기름은 선택한 시즌·무기에 대한 정확한 SimC 입력과 고정 O가 검증된 환경에서만 적용되며, 미검증 선택은 임의의 0으로 처리하지 않고 차단합니다.

    검증된 기름 조합을 고르면 적용 손이 자동 표시됩니다. 손을 직접 바꾼 경우에도 정확한 검증 설치 구성과 일치해야 계산할 수 있습니다.

    검증된 무기 기름 ItemID 지정 (선택형 고급 설정)

    위에서 적용할 무기 손을 먼저 체크하세요. ItemID를 입력하면 해당 손의 검증·설치된 v212 시즌 기름과 정확히 대조합니다. 여러 손을 선택하면 각 손의 ID를 모두 지정해야 합니다. ID를 비우면 기존 손별 선택 방식이 유지되며, 같은 손에 검증된 기름이 여러 종류면 임의 선택하지 않습니다. 기름의 효과·정적 rating은 직접 입력하지 않습니다. 위 목록은 봉인된 설치 조합만 표시하며 품질 우위를 추정하지 않습니다.

    죽음의 기사 룬벼리기 · 영구 무기 강화

    특수효과 장비 · 장식원하는 경우 선택

    일반 장비·티어4세트와 선택한 장식 제작장비의 정확한 ID는 내부에서 구성합니다. 특수장비의 보너스·촉매 원본 ID도 일반 사용자에게 입력받지 않습니다. 이미 저장된 로컬 정적 캐시는 자동으로 찾아 사용하며, 정확한 L이 있는 경우 그대로 재사용합니다. 누락된 경우 '예산 미리 확인'(Native 0회)은 차단될 수 있으나, 사용자가 'SimC 최적화 실행'을 승인하면 내부 생성한 대표 프로필에서 정적 SimC Native 최대 1회로 선택 장비의 정확한 L을 확보·캐시합니다. 이후 최적화 계산을 진행하며, 미확정 L을 0으로 간주하지 않습니다. 현재 검증된 장식은 일반 방어구용 안감 2종입니다. 목걸이·반지·무기용 장식은 별도의 실제 호환 토큰이 검증되기 전까지 선택할 수 없습니다.

    장식별 장착 가능한 부위만 표시됩니다. 장신구·무기 장식은 검증된 선택지가 아직 없습니다.

    음식 · 물약 · 보석 · 특수 콘텐츠선택 설정

    영약 F는 선택한 시즌 검증 설치본의 정적 rating을 따르며, 다른 구성에 과거 F 값을 복사하지 않습니다. Omnium은 기존 다른 열을 유지하고 4열의 치명·가속·특화·유연만 선택합니다. 새 조합의 SimC 수용 여부는 실행 결과로 확인합니다.

    마법부여확인된 효과만 선택

    확인된 음식·물약·증강룬·다이아몬드와 방어구 안감은 위 선택 항목에 이미 연결되어 있습니다. 최고 품질 마법부여는 부위별 목록을 확보했지만, 선택 시 CHMV 예산에 반영될 정확한 정적 수치와 Native 수용 확인 전까지 잠금 상태로 표시합니다.

    시즌 데이터와 SimC 출처를 확인하는 중…

    독수리의 눈(치명타 효과 강화)은 고정 CHMV rating 증가가 없어 B/T를 바꾸지 않습니다. 효과 및 DPS는 SimC가 처리하며, 다른 37종은 아직 미검증 선택 잠금입니다.

    영약 F, 일반 보석 J 및 무기 기름 O의 기존 예산은 그대로 유지됩니다. 원시 DB2 후보를 임의로 유효한 SimC 선택으로 표시하지 않습니다.
