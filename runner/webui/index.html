STEP 01 · CHARACTER & TARGET

최적화 조건

지원 전문화 베타

SimC 프로필에서 캐릭터 정보 가져오기 (선택)현재 장비·스탯은 가져오지 않음

원본 파일은 브라우저 내부에서만 열며 서버에 전송하거나 저장하지 않습니다. 장비·장신구·보석·현재 CHMV 데이터는 가져와 적용하지 않습니다. 전문화가 변경되면 해당 전문화 기본 입력으로 전환됩니다.

이번 시즌 장신구·특수효과 선택 목록 확인 중 · 일반장비·티어·무기는 내부 자동 구성

최신 시즌 대표 장비·직업별 티어 4세트·무기는 항상 내부 구성합니다. 목표 아이템레벨 266~344에 맞춘 독립 세션입니다.

실제 SimC 대표 프로필 26/26 수용 검증. 기본 경로의 기존 세션·캐시는 유지하며, 새 선택은 별도 캐시에서 기존 6후보 최적화를 실행합니다. 다른 특성·장신구·특수효과 조합의 성공 여부는 각 SimC 실행으로 판단합니다.

선택 특수효과 장비 · 장식특수효과 장비 부위 자동 결정 · 장식 종류별 적용 부위 제한

일반 장비·티어4세트와 선택한 장식 제작장비의 정확한 ID는 내부에서 구성합니다. 특수장비의 보너스·촉매 원본 ID도 일반 사용자에게 입력받지 않습니다. 이미 저장된 로컬 정적 캐시는 자동으로 찾아 사용하며, 선택 특수장비의 정확한 Native 정적 L이 없으면 추정하지 않고 계획 단계에서 차단합니다. 현재 검증된 장식은 일반 방어구용 안감 2종입니다. 목걸이·반지·무기용 장식은 별도의 실제 호환 토큰이 검증되기 전까지 선택할 수 없습니다.

장식별 장착 가능한 부위만 표시됩니다. 장신구·무기 장식은 검증된 선택지가 아직 없습니다.

소모품 · 다이아몬드 · Omnium소스 관측 선택지만 제공

영약은 검증된 원본 고정치 F=165를 유지합니다. Omnium은 기존 다른 열을 유지하고 4열의 치명·가속·특화·유연만 선택합니다. 새 조합의 SimC 수용 여부는 실행 결과로 확인합니다.
